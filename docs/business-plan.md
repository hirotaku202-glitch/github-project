## 0. エグゼクティブサマリー

CEOは、中京圏（愛知・三重・滋賀）で美容・脱毛・フィットネスの複合店を
運営する **株式会社GIL** の全事業を **事業譲渡** で買収する。
買収後、GILの5ブランドをすべて維持しつつ、ブランドごとに最適な成長戦略を
適用し、3年で拠点数を4 → 約12へ拡大する。

| 項目 | 内容 |
|---|---|
| 買収対象 | 株式会社GIL（4拠点・5ブランドの複合店事業） |
| 買収方式 | **事業譲渡**（店舗・設備・賃借権・顧客データ・スタッフ雇用・FC加盟契約を個別承継） |
| 譲受側 | CEOが設立する新運営会社（本計画で「新運営会社」と表記） |
| 現状業績 | 全社でトントン〜微赤字（再生対象） |
| 取得想定額 | 約 ¥4,000万（資産時価＋のれん。微赤字のため営業権は控えめ） |
| 収益構成 | 施術売上 約95% / 店販（物販）約5% |
| 3年後目標 | 約12拠点 / 全社売上 約3.2億円 / 営業利益率 約13% |

**成長の型**: ①事業譲渡でGILの拠点・ブランド・顧客を一括取得 → ②全社を再生
（トントン〜微赤字 → 黒字化）→ ③ブランド別に成長戦略を分けて適用。

## 1. 買収対象 — 株式会社GILの全体像

GILは「1拠点に複数業態を集める複合店」を特徴とする。これが事業の複雑性であり、
同時に強み（同一客層への複数サービス提供・賃料効率）でもある。

### 1.1 拠点とブランド構成

|---|---|---|
| 名古屋店 | 愛知 | メンズ脱毛BOSS（FC加盟）＋ 眉毛サロン8BROW ＋ GOAT TrainingGYM の複合店 |
| 八日市店 | 滋賀（東近江） | Beauty Bright ＋ 眉毛サロン8BROW の複合店 |
| 桑名店 | 三重 | Lim eyelash（まつげサロン） |

|---|---|---|---|

## 2. 買収スキーム — なぜ「事業譲渡」か

事業譲渡は、譲渡対象を契約で個別に指定する方式。GILの買収において重要な
論点は以下のとおり。

### 2.1 事業譲渡のメリット

- **簿外債務の遮断**: 売り手（GIL）の未払金・係争・税務リスク等を原則引き継がない。
  トントン〜微赤字の会社を買ううえで、この遮断効果は必須。
- **対象の取捨選択**: 4拠点・5ブランドのうち、不要・不採算のものを対象から
  外せる（今回は全ブランド維持方針のため全店取得）。

### 2.2 事業譲渡で必ず対応すべき手続き（複合店ゆえに重い）

| 項目 | 対応 |
|---|---|
| 賃貸借契約 | 4拠点すべて、貸主の承諾を得て契約上の地位を承継 |
| **FC加盟契約（メンズ脱毛BOSS）** | BOSS本部の承諾を得て加盟店の地位を承継、または新運営会社で再加盟 |
| 各種許認可 | 美容所登録・各業態の保健所届出を譲受側で取得し直す |
| 顧客データ | ブランドごとの顧客・予約データの引き渡しと個人情報の移管同意 |
| スタッフ | 全スタッフと譲渡後の雇用契約を巻き直し、処遇を提示して定着を図る |
| 取引先契約 | 材料仕入・予約システム・POS・ジム機器リース等を承継または再契約 |
| 消費税 | 事業譲渡対価には消費税が課税される点を資金計画に織り込む |

> **FC加盟店（BOSS）の承継可否がDDの最重要論点**。本部の承諾が前提。

## 3. デューデリジェンス（DD）論点

| 領域 | 確認事項 |
|---|---|
| 拠点別損益 | 4拠点 × 各ブランドの損益を分解し、赤字の所在を特定 |
| 赤字要因 | 立地起因か／単価か／稼働率か／人件費か／集客か（再生可否の判断軸） |
| 複合店の配賦 | 1拠点に複数業態が同居 → 賃料・人件費・共通費の配賦を精査 |
| FC契約 | BOSSのロイヤリティ率・契約残存期間・承継条件・競業制限 |
| ジム会員 | GOATの会員数・継続率・機器のリース残債 |
| 賃貸借 | 各拠点の残存期間・更新料・原状回復義務・承継承諾 |
| スタッフ | 業態別の有資格者数・スキル・給与水準・離職リスク |
| 顧客資産 | ブランド別のリピート率・会員数・予約データの質 |

## 4. ブランド別 成長戦略（買収後）

全ブランドを維持しつつ、ブランドごとに役割を分ける。これが本計画の核心。

### 4.1 Lim eyelash — 多店舗化の主力

- まつげサロンは反復来店性が高く（3〜4週ごと）、LTVが大きい。
- 現在1拠点（桑名）。**標準店モデルを確立し、中京圏で多店舗展開**する。
- 8BROW（眉毛）との親和性が高く、**8BROWとの併設複合店**を出店の基本形にする。
- 目標: 3年で 1 → 5拠点。

### 4.2 8BROW — 出店継続でドミナント形成

- 既に3拠点で運営ノウハウが蓄積。グループの主力業態。
- Lim eyelashとの併設、または単独で**中京圏に出店を継続**。
- 目標: 3年で 3 → 6拠点。

### 4.3 メンズ脱毛BOSS — 8BROW併設でのみ展開

- FC加盟業態のため単独出店はせず、**新規出店時に8BROWへ併設する形でのみ展開**。
- 男性客の取り込みと複合店の集客力強化に寄与。
- 出店はBOSS本部との加盟条件の合意が前提。

### 4.4 GOAT TrainingGYM — 名古屋拠点のみ維持

- ジムは設備投資・運営ノウハウが他業態と異なり、横展開しない。
- **名古屋複合店の差別化要素として現状を維持・最適化**する（拡大対象外）。

### 4.5 Beauty Bright — 八日市拠点で維持

- 八日市複合店の一業態として維持。横展開は当面行わない。
- 8BROWとの併売で複合店の客単価・来店動機を支える。

### 4.6 複合店モデルの標準化

新規出店の基本形を「**8BROW ＋ Lim eyelash（＋必要に応じてBOSS）**」の
美容複合店とする。眉・まつげ・メンズ脱毛は客層が重なり、同一フロアで
クロス送客でき、賃料・受付・予約システムを共有できる。

## 5. 再生プラン（買収後12ヶ月）

トントン〜微赤字を黒字化する。施術業の利益ドライバーに沿った打ち手。

| 打ち手 | 内容 | 効果 |
|---|---|---|
| ① 拠点別損益の可視化 | 店舗管理システム（`admin/`）で拠点×ブランド別にKPIを管理 | 赤字の所在を特定 |
| ② 稼働率改善 | 予約システム統一、空き枠可視化、次回予約・指名の徹底 | ベッド稼働率 +15pt |
| ③ 客単価改善 | メニュー再設計、回数券・サブスク、クロスセル（眉↔まつげ） | 客単価 +10% |
| ④ 店販強化 | ホームケア商品の提案標準化 | 店販比率 5% → 10% |
| ⑤ 集客の本部化 | 自社サイト・SNS・予約媒体を本部運用に集約 | CAC低減・新規増 |
| ⑥ コスト最適化 | 共同購買、シフト最適化、複合店の共通費見直し | 原価・人件費率 改善 |
| ⑦ 人材定着 | 評価制度・指名インセンティブ・研修で離職抑制 | 品質と生産性の安定 |

## 8. 組織・オペレーション

### 8.1 本部機能の構築

買収時点でGILには十分な本部機能がない可能性が高い。再生と拡大には本部が必須。

- CEO・運営本部長・教育マネージャー・エリアSV・経理／総務
- 全拠点のKPIを店舗管理システム（`admin/`）で週次モニタリング

### 8.2 標準化

- ブランドごとの施術マニュアル・カウンセリングスクリプトを整備
- 入社研修プログラムを全拠点共通で実施

### 8.3 KPI

拠点×ブランド別に: ベッド稼働率／客単価／新規・リピート比率／
スタッフ1人あたり売上／指名率／店販比率。

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| 赤字が構造的（立地起因） | DDで拠点×ブランド別に赤字要因を特定。構造赤字は減額交渉 |
| FC加盟契約（BOSS）を承継できない | 締結前にBOSS本部の承諾を取得。不可なら再加盟または当面BOSS停止 |
| 賃貸借契約を承継できない | 締結前に各貸主の承諾を取得 |
| スタッフの離職 | 譲渡前に処遇提示、評価・インセンティブで定着 |
| 簿外債務 | 事業譲渡スキームで遮断＋表明保証条項 |
| 複合店ゆえの管理の複雑さ | 店舗管理システムで拠点×ブランドの損益を一元可視化 |
| 多ブランドで経営資源が分散 | ブランド別の役割を明確化（4章）。拡大対象を絞る |
