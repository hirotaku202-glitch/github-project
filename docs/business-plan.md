## 0. エグゼクティブサマリー

当社は眉毛サロン「**ARCH 表参道店**」（1号店・黒字運営中）を運営している。
本計画では、収支がトントン〜微赤字の眉毛サロン**小規模チェーン3店舗を「事業譲渡」
で買収**し、即時に4店舗体制へ拡大。買収店を再生（黒字化）したうえで、
3年間で **直営10店舗＋FC15店舗（計25店舗）** へ成長させる。

| 項目 | 内容 |
|---|---|
| 既存事業 | ARCH 表参道店（月商 約350万円・営業利益率 約18%） |
| 買収対象 | 眉毛サロン3店舗チェーン（収支トントン〜微赤字） |
| 買収方式 | **事業譲渡**（店舗・設備・賃借権・顧客データ・スタッフ雇用を取得） |
| 取得想定額 | 約 ¥3,000万（資産時価 約¥1,800万＋のれん 約¥1,200万） |
| 買収後 | 即 4店舗。12ヶ月で買収3店を黒字化 |
| 3年後目標 | 25店舗 / 全社売上 約4.9億円 / 営業利益率 15% |

**成長の型**: ①買収で店舗網を一気に取得 → ②買収店を再生 → ③本部機能で標準化
→ ④直営の利益再投資＋FC で面展開 → ⑤連続買収（ロールアップ）で加速。

## 1. なぜ「買収」で伸ばすのか — グロース戦略の中核

ゼロから出店すると、1店舗あたり内装・採用・集客の立ち上げに6〜12ヶ月を要する。
一方、既存サロンの**事業譲渡**なら、以下を「初日から」獲得できる。

- 稼働中の店舗（内装・設備）と立地（賃貸借契約の地位）
- 既存スタッフ（技術者の採用コストと育成期間を圧縮）
- 顧客リスト・予約データ・リピート基盤（売上が初月から立つ）

買収対象は「トントン〜微赤字」。これは**価格が安く買え、かつ伸びしろが大きい**
ことを意味する。経営の巧拙で赤字なだけで、立地・顧客・スタッフという資産は
生きている。当社の運営ノウハウ（表参道店で実証済み）を注入すれば黒字化できる。

> **当社の成長エンジン = 「割安な不振サロンを買い、当社の型で再生し、束ねる」**
> = スモール・ロールアップ戦略。

### なぜ「株式譲渡」でなく「事業譲渡」か

事業譲渡は、譲渡対象を契約で個別に指定する。よって**売り手企業の簿外債務・
偶発債務（未払金、係争、税務リスク等）を原則として引き継がない**。
不振企業の買収ではこの遮断効果が極めて重要。デメリット（許認可・契約の
再取得、消費税課税、雇用の再契約）は、店舗数が少ない今回の規模なら管理可能。

## 2. 買収対象のデューデリジェンス（DD）論点

事業譲渡で取得するため、以下を契約締結前に精査する。

| 領域 | 確認事項 |
|---|---|
| 賃貸借契約 | 3店舗すべて、貸主の承諾を得て契約上の地位を承継できるか／残存期間・更新料・原状回復義務 |
| 設備・内装 | 取得資産の時価査定、老朽度、追加投資の要否 |
| 顧客データ | 顧客リスト・予約データの引き渡し可否と個人情報の同意・移管手続き |
| スタッフ | 各店スタッフの人数・スキル・給与水準、譲渡後の雇用契約の巻き直しと定着 |
| 取引先契約 | 材料仕入・予約システム・POS等の契約の承継または再契約 |
| 赤字要因 | トントン〜微赤字の原因分析（立地か／単価か／稼働率か／人件費か／集客か） |
| 競業避止 | 譲渡契約に売り手の競業避止義務を明記 |
| 許認可 | 美容所登録・保健所届出を譲受側で取り直す段取り |

**赤字要因の特定が買収判断の鍵**。立地起因の構造赤字なら撤退前提で減額交渉、
オペレーション起因なら再生可能 = 買い、という判断基準を持つ。

## 4. 市場分析

### 4.1 市場機会

- 眉毛サロン市場はSNS需要と美容意識の高まりで拡大基調。
- 「眉毛専門」業態はブランドによる面展開の余地が大きい。
- 1施術が短時間 = **席あたり回転率が高く**、小型・低投資で出店可能（10〜15坪）。
- 個人・小規模オーナーが多く、後継者難・経営難の**売り案件が継続的に発生** =
  ロールアップの母集団が豊富。

### 4.2 ターゲット顧客

| セグメント | 比率想定 | 特徴 |
|---|---|---|
| 20〜34歳 女性（メイン） | 60% | SNS起点、月1回の定期来店 |
| 35〜49歳 女性 | 20% | エイジング対応・印象管理 |
| 男性（身だしなみ） | 15% | 就活・ビジネス、伸びしろ大 |
| 学生 | 5% | 学割で早期囲い込み |

### 4.3 差別化

| 競合タイプ | 当社の差別化 |
|---|---|

## 5. 買収店の再生プラン（買収後12ヶ月）

トントン〜微赤字の3店を、当社の型で黒字化する。標準的な打ち手は以下。

| 打ち手 | 内容 | 効果 |
|---|---|---|
| ① ブランド統一 | 店名を「ARCH」へ統一、内装・サイン・接客を表参道基準に | 単価・信頼の底上げ |
| ② メニュー再設計 | 低単価メニュー偏重を是正、眉毛パーマ等の高単価枠を導入 | 客単価 +10〜20% |
| ③ 稼働率改善 | 予約システム統一、空き枠の可視化、指名・次回予約の徹底 | 席稼働率 +15pt |
| ④ 集客の本部化 | 自社サイト・SNS・予約媒体を本部運用に集約 | CAC低減・新規増 |
| ⑤ コスト最適化 | 仕入の共同購買、シフト最適化、不採算枠の整理 | 原価・人件費率 改善 |
| ⑥ 人材定着 | 評価制度・指名インセンティブ・研修で離職を抑制 | 品質と生産性の安定 |

**再生の収支イメージ（買収店1店あたり・月次）**

| 指標 | 買収時 | 再生後（12ヶ月） |
|---|---|---|
| 月商 | 約 ¥190万 | 約 ¥290万 |
| 客単価 | 約 ¥4,700 | 約 ¥5,700 |
| 席稼働率 | 約 48% | 約 68% |
| 営業損益 | ▲¥5万〜±0 | ＋¥45万（利益率 約16%） |

## 7. オペレーションと組織

### 7.1 標準化（多店舗運営の要）

- 施術マニュアル・カウンセリングスクリプトの統一
- 「ARCHアカデミー」: 入社後4週間の技術研修を全店共通で実施
- **店舗管理システム**（本リポジトリ `admin/`）で全店のKPIを本部が一元監視

### 7.2 KPI管理

各店を週次でモニタリング: 席稼働率／客単価／新規・リピート比率／
スタッフ1人あたり売上／指名率。

### 7.3 組織

- 本部: CEO・運営本部長・教育マネージャー・エリアSV（6店に1名）・M&A担当
- 店舗: 店長1＋アイブロウスタイリスト3〜4

## 10. リスクと対策

| リスク | 対策 |
|---|---|
| 買収店の赤字が構造的（立地起因） | DDで赤字要因を特定。構造赤字店は減額交渉 or 対象から除外 |
| 賃貸借契約を承継できない | 締結前に貸主の承諾を取得。承諾不可の店は対象外に |
| 買収店スタッフの離職 | 譲渡前に処遇を提示、評価・インセンティブで定着 |
| 簿外債務 | 事業譲渡スキームで遮断＋表明保証条項 |
| 再生が想定より遅れる | アーンアウトで対価を成果連動化、四半期で軌道修正 |
| 出店ペースに採用が追いつかない | ARCHアカデミーで未経験者を内製育成 |
