## 2. ブランドコンセプト

> **「3分の印象を、つくる。」**
>
> 顔の印象の大半は眉で決まる。ARCHは骨格と毛流れを読み解き、
> その人だけの"似合う眉"をデザインする。高度な技術を、
> 背伸びしない価格で、通いやすい場所で。

### ブランドの約束（Brand Promise）

1. **似合う**: 流行ではなく、骨格に基づくパーソナルデザイン。
2. **続けやすい**: 通える価格と、駅近・短時間の利便性。
3. **安心**: 全店共通の研修を受けたスタイリストと、統一された品質。

## 4. ビジュアルアイデンティティ

### 4.1 ロゴ

ワードマーク「ARCH」。`A` の頂点を眉のアーチに見立てる。
シンボルは `assets/logo.svg` を参照（眉のアーチを抽象化した弧）。

- 余白: ロゴ高さの50%以上を周囲に確保
- 最小サイズ: 横幅 24px 以上
- 禁止: 変形・回転・影・グラデーション・指定色以外での着色

### 4.2 カラーパレット

| 役割 | 色名 | HEX | 用途 |
|---|---|---|---|
| プライマリ | ダークブラウン | `#3E2C23` | ロゴ・見出し・テキスト |
| セカンダリ | モカベージュ | `#C8A98F` | 装飾・罫線・サブ要素 |
| アクセント | テラコッタ | `#A8744F` | ボタン・CTA・強調 |
| ベース | アイボリー | `#F5EFE8` | 背景 |
| ニュートラル | オフホワイト | `#FFFFFF` | カード・余白 |
| 文字（淡） | グレージュ | `#7A6E63` | 補足テキスト |

ブラウン基調で「上質・落ち着き・肌なじみ」を表現する。

### 4.3 タイポグラフィ

- 見出し: 明朝系（上品さ・余白）
- 本文・UI: ゴシック系（可読性）
- 英字: クラシックなセリフ／サンセリフを用途で使い分け

### 4.4 トーン＆マナー

- 写真: 自然光、肌の質感、ビフォーアフターは誇張しない
- 文体: ていねい・等身大。専門用語は噛み砕く。過度な煽りをしない。
- NG: 過度な「盛り」表現、不安を煽る訴求、価格だけの安売り訴求

## 6. 接客・体験の標準（カスタマージャーニー）

1. **来店・カウンセリング**: 骨格・毛流れ・なりたい印象をヒアリング（5分）
2. **デザイン提案**: ペンシルで仕上がりを可視化し、合意してから施術
3. **施術**: ワックス／シェービング／パーマ。痛み・仕上がりを都度確認
4. **アフター**: ホームケア説明、次回来店目安（4〜6週間後）の案内
5. **次回予約**: その場で次回枠を確保（リピート率を支える要）

## 7. 買収店のリブランド手順

| ステップ | 内容 |
|---|---|
| 1. サイン・内装 | 旧店名サインを撤去、ARCHロゴ・カラーへ更新 |
| 2. メニュー統一 | 価格・メニュー名を本書のとおりに改定 |
| 3. 接客研修 | 全スタッフにARCHアカデミーの接客標準を研修 |
| 4. 顧客告知 | 既存顧客へリブランドと特典を案内（離反防止） |
| 5. デジタル | 予約サイト・SNSをARCH本部アカウントへ統合 |

旧ブランドの顧客資産を失わないよう、**リブランドは「値上げ」ではなく
「品質向上」として伝える**。初回はリブランド記念特典を用意する。
