## 2. グループ共通の設計指針

複数ブランドでも、運営会社としての品質・体験には一貫性を持たせる。

### 2.1 共通の約束（Group Promise）

1. **似合う／結果が出る**: 流行ではなく一人ひとりに合わせた提案。
2. **続けやすい**: 通える価格・予約のしやすさ・駅近やロードサイドの利便性。
3. **安心**: 研修を受けたスタッフと、全拠点で統一された衛生・接客の基準。

### 2.2 共通オペレーション基準

- 予約: ホットペッパービューティー（HPB）を全ブランド共通の予約基盤とする
- カウンセリング: 「ヒアリング → 仕上がりの可視化 → 合意 → 施術 → 次回予約」
- 衛生: 器具の消毒・使い捨て徹底、施術スペースの清掃チェックリスト
- 店販: ホームケア商品の提案を施術後フローに標準で組み込む

### 2.3 複合店での見せ方

1拠点に複数ブランドが同居する複合店では、各ブランドのサインを明確に分けつつ、
受付・待合は共通とし、相互送客（眉↔まつげ↔脱毛）を促す導線にする。

## 3. ブランド別 設計

### 3.1 〈Lim〉ブランドファミリー — 成長の軸

まつげ「Lim eyelash」と眉毛「Lim brow」を同一拠点に併設し、〈Lim〉として
目もとをトータルにデザインする。眉とまつげは客層・来店周期が重なり、
相互送客が効く。眉毛ブランドは将来的にLim browへ一本化する。

- 共通の世界観: ロゼベージュ〜くすみピンク基調。やわらかく洗練された印象。
- 〈Lim〉の各ブランドはロゴタイプ「Lim」を共有し、サブネーム
  （eyelash / brow）で業態を示す。
- 新規出店は「Lim eyelash ＋ Lim brow」のLim複合店を標準形とする。

## 4. 共通ビジュアル指針

各ブランドは独自のロゴ・カラーを持つが、運営会社レベルでは以下を統一する。

- 写真: 自然光、施術部位の質感、ビフォーアフターは誇張しない
- 文体: ていねい・等身大。専門用語は噛み砕く。不安を煽らない。
- 予約導線: グループサイト（`site/`）の各店舗カードからHPB店舗ページへ誘導
- NG表現: 過度な「盛り」、不安訴求、価格だけの安売り訴求
