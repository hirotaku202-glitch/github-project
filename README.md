# GIL 美容複合サロングループ — 買収・多店舗展開プロジェクト

CEOとして、美容・脱毛・フィットネスの複合店を運営する **株式会社GIL** を
**事業譲渡** で買収し、多店舗展開していくための計画とツール一式。

## 背景

GILは中京圏（愛知・三重・滋賀）で4拠点・5ブランドの複合店を運営。
収支はトントン〜微赤字で、買収後の再生と成長が課題。買収後はまつげ
「Lim eyelash」に眉毛の新ブランド「Lim brow」を併設し、〈Lim〉ブランド
ファミリーを成長の軸に据える。

| ブランド | 業態 | 成長方針 |
|---|---|---|
| Lim eyelash | まつげサロン | 多店舗化の主力。Lim brow併設の「Lim複合店」を標準形に |
| Lim brow | 眉毛サロン（新ブランド） | Lim eyelash併設で新規出店。眉毛の新規出店ブランド |
| 8BROW | 眉毛サロン | 既存3拠点を維持。眉毛の新規出店はLim browで |
| メンズ脱毛BOSS | メンズ脱毛（FC加盟） | Lim複合店併設でのみ展開 |
| GOAT TrainingGYM | トレーニングジム | 名古屋のみ維持 |
| Beauty Bright | 美容（エステ系） | 八日市で維持 |

## 構成

```
docs/business-plan.md   事業計画書（買収＋多店舗グロース計画）
docs/brand.md           ブランド設計書（5ブランド）
admin/                  店舗管理システム（拠点×ブランドのKPI管理）
site/                   コーポレートサイト（ブランド・店舗紹介。予約はHPBへ誘導）
assets/logo.svg         グループロゴ
```

予約はホットペッパービューティー（HPB）を利用する。自社サイトは
ブランド・店舗の紹介と、HPBの店舗ページへの予約導線を担う。

## 動かし方

ビルド不要。静的ファイルのみで動作する。

```bash
# リポジトリ直下で簡易サーバを起動
python3 -m http.server 8000
```

- コーポレートサイト: http://localhost:8000/site/
- 店舗管理システム: http://localhost:8000/admin/

## 各ツール

### 店舗管理システム（admin/）

- ダッシュボード: 全社KPI、ブランド別・拠点別の当月売上、成長方針サマリー
- 拠点 / ブランド / 予約 / スタッフ / 売上 の各タブで管理
- データはブラウザのlocalStorageに保存。「データ初期化」で初期状態に戻せる
- 「予約」タブは、HPB経由の予約を手入力で記録・管理する用途

### コーポレートサイト（site/）

- ブランド・店舗を紹介する集客サイト
- 予約はホットペッパービューティーの店舗ページへ誘導する
- 各店舗カードの予約リンクは、HPBの店舗別ページURLに差し替えて使う

## 注意

- 数値（売上・利益等）はGILの実財務が未開示のための想定値。DD完了後に更新する。
- メンズ脱毛BOSSはFC加盟ブランドのため、VI・価格はFC本部規定が優先。
