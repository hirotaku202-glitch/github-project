# GIL 美容複合サロングループ — 買収・多店舗展開プロジェクト

CEOとして、美容・脱毛・フィットネスの複合店を運営する **株式会社GIL** を
**事業譲渡** で買収し、多店舗展開していくための計画とツール一式。

## 背景

GILは中京圏（愛知・三重・滋賀）で4拠点・5ブランドの複合店を運営。
収支はトントン〜微赤字で、買収後の再生と成長が課題。全ブランドを維持しつつ、
ブランドごとに成長方針を分けて拡大する。

| ブランド | 業態 | 成長方針 |
|---|---|---|
| 8BROW | 眉毛サロン | 出店継続（主力） |
| Lim eyelash | まつげサロン | 多店舗化（最優先） |
| メンズ脱毛BOSS | メンズ脱毛（FC加盟） | 8BROW併設でのみ展開 |
| GOAT TrainingGYM | トレーニングジム | 名古屋のみ維持 |
| Beauty Bright | 美容（エステ系） | 八日市で維持 |

## 構成

```
docs/business-plan.md   事業計画書（買収＋多店舗グロース計画）
docs/brand.md           ブランド設計書（5ブランド）
admin/                  店舗管理システム（拠点×ブランドのKPI管理）
site/                   予約・集客サイト（コーポレート＋WEB予約）
assets/logo.svg         グループロゴ
```

## 動かし方

ビルド不要。静的ファイルのみで動作する。同一オリジンで配信すると、
予約サイトの申込が店舗管理システムの「予約」に自動で反映される
（localStorageを共有するため）。

```bash
# リポジトリ直下で簡易サーバを起動
python3 -m http.server 8000
```

- 予約・集客サイト: http://localhost:8000/site/
- 店舗管理システム: http://localhost:8000/admin/

## 各ツール

### 店舗管理システム（admin/）

- ダッシュボード: 全社KPI、ブランド別・拠点別の当月売上、成長方針サマリー
- 拠点 / ブランド / 予約 / スタッフ / 売上 の各タブで管理
- データはブラウザのlocalStorageに保存。「データ初期化」で初期状態に戻せる

### 予約サイト（site/）

- コーポレートサイト（ブランド・店舗紹介）とWEB予約フォーム
- 店舗 → ブランド → メニュー の順に選択して予約
- 予約データは `gil_bookings` に保存され、店舗管理システムと連携

## 注意

- 数値（売上・利益等）はGILの実財務が未開示のための想定値。DD完了後に更新する。
- メンズ脱毛BOSSはFC加盟ブランドのため、VI・価格はFC本部規定が優先。
